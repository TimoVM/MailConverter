TimoVM's Mail Writer code converter

Intended to be used with TimoVM's Mail Writer setup as outlined here. MailConverter based on the original implementation by Scotteh.

Please note that all blank tiles at the end of a mail need to be entered one by one manually. This will prevent the Mail Writer from producing an incorrect result.

Underneath each mail you can find a copy represented in flat text. Each character that needs to be entered is separated by blank spaces, character within nicknames are case sensitive. Please mind the following special characters:

  • [SPACE] represents a blank space. (lowercase menu, 5th row, rightmost column)
  • * represents a multiplication marker. (uppercase menu, 5th row, rightmost column)
  • pk represents the pk symbol (uppercase menu, 5th row, leftmost column)
  • mn represents the mn symbol (uppercase menu, 5th row, 2nd column from left)
  • po represents the po symbol (uppercase menu, 5th row, 3rd column from left)
  • ké represents the ké symbol (uppercase menu, 5th row, 4th column from left)
  • ¥ represents the pokédollar symbol (uppercase menu, 5th row, 3rd column from right)
  • … represents the ellipsis symbol (uppercase menu, 5th row, 2nd column from right)
  • 『 represents the left quotation symbol (lowercase menu, 5th row, leftmost column)
  • 』 represents the right quotation symbol (lowercase menu, 5th row, 2nd column from left)
